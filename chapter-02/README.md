# فصل دوم نیازسنجی آموزشی رایان

پیش‌نویس بر اساس متن و نمودارهای قابل مشاهده. صوت و ویدئوی درس هنوز پیاده و تطبیق داده نشده‌اند. شرح صوتی تصویرهای روش‌های شناسایی و چهار سطح منشأ نیاز در دسترس نبود.

فایل Word صفحه‌بندی ثابت دارد و متن آن به شکل تصویر صفحات است. متن قابل ویرایش در JSON و HTML قرار دارد. PDF متن قابل جست‌وجو دارد. مثال‌ها فرضی و توضیح‌های تکمیلی از بازنویسی درس جدا شده‌اند.

منبع: https://itcsam.ir/Files/SCORM_Courses/Course2840/7544ad33-ea5a-4ef6-8cca-a1704f8d859b/index_lms_html5.html

تاریخ بررسی: ۲۰۲۶/۱۱/۱۴، برابر با ۲۳ آبان ۱۴۰۵.

## ساخت

قلم B Nazanin و نسخه‌ی پررنگ آن باید در سیستم نصب باشند. Python با python-docx و Node با Playwright لازم‌اند. مسیر runtime را با متغیر RAYAN_RUNTIME و مسیر Chrome را با CHROME_PATH می‌توان تعیین کرد.

۱. `python source/build.py`
۲. `node source/render.cjs`
۳. بررسی همه‌ی تصویرهای پوشه‌ی qa و فاصله‌ی متن از پانوشت.
۴. `python source/finalize_word.py`
۵. `python source/package_source.py`

قالب A5 افقی، قلم بی‌نازنین، لوگوی اصلی رایان، رنگ‌های سرمه‌ای 14334D و زرشکی B91E31 و واترمارک رایان حفظ شده‌اند. قلم‌ها داخل بسته‌ی منبع توزیع نمی‌شوند.
